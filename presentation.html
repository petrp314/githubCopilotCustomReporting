05 / Readiness & next steps

Designed to be gated. Not yet live.

The implementation is a conditional foundation. Tenant approval and operational acceptance come before a pilot.

Implemented foundation

IN REPOSITORY
  • Standard-library Python collector and protected SQLite history
  • Aggregate transformation, cohort suppression, and static dashboard
  • Fail-closed publication preflight and strict artifact allowlist
  • Synthetic demo and automated tests—no live enterprise data

Before a live pilot

PENDING
  • Tenant access and source-schema validation; reconcile representative exports
  • Finance, privacy, architecture, and publication-audience approval
  • Private organization project Pages, protected runner, encrypted storage, and secrets
  • Verify access denial, backups, recovery, retention, alerting, and operations
Current status: approval gates are not satisfied; live collection and deployment are not approved. The personal-owner repository is not an eligible enterprise Pages target. Different audiences or row-level access would require a separately designed authenticated backend.
